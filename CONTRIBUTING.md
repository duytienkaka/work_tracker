# Contributing

Thank you for helping improve Work Tracker.

## Coding style

- Follow the existing Dart style in the project.
- Prefer clear names and small, focused widgets.
- Keep changes scoped to the task at hand.

## Formatting

Run the formatter before submitting changes:

```bash
dart format .
```

## Quality checks

Before opening a pull request, run:

```bash
flutter analyze
flutter test
```

## Commit message convention

Use concise, descriptive commit messages such as:
- feat: add new dashboard summary
- fix: resolve shift refresh issue
- docs: improve repository documentation
